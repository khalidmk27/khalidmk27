## Featured Projects

### [ESP32-C6 / STM32F410RB PPP Bridge](https://github.com/khalidmk27/ESP32C6-STM32F410RB-PPP-BRIDGE)
A dual-MCU gateway combining an ESP32-C6 and STM32F410RB. The project explores firmware development with ESP-IDF and Embassy Rust, along with UART-based PPP networking, Wi-Fi, HTTP, and MQTT.

### [IoT Conveyor Monitor](https://github.com/khalidmk27/IoT-Conveyor-Monitor-for-Counting-and-Fall-detection)
An IoT monitoring project that counts objects on a conveyor using an IR sensor and detects disturbances such as collisions or falls with a vibration sensor.

### [Bluetooth Door Monitoring System](https://github.com/khalidmk27/Bluetooth-Door-Monitoring-System)
An Arduino-based door monitoring system using an IR sensor, buzzer, and Bluetooth module. Bluetooth commands allow monitoring to be enabled or disabled remotely.

### [STM32F4 LED Blink](https://github.com/khalidmk27/STM32F4-LED-BLINK)
A Rust-based introductory firmware project that blinks the user LED on an STM32F410RB Nucleo board.
